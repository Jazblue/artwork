# Jazblue Artwork

Personal artwork repository by Jazblue (Jason Harvey).

## Website
Live at: https://jazblue.github.io/artwork

## Repository Structure

- `picture/` — JPEG/PNG artwork gallery (20+ images)
  - gothrevenge.jpeg, harveystylemega.jpeg, pic1.jpeg–pic20.jpeg
  - plus other assorted images
- `video/` — MP4 videos and audio clips
  - Includes Jason CV videos, dog videos, raver visuals, etc.
- `index.html` — Main artwork page with embedded videos and image gallery
- `page2.html` — Secondary page with cat/dog humor theme
- `counter.js` — Visitor counter (hits countapi.mileshilliard.com)

## Contents
- Picture gallery with diverse themes (tech, art, lifestyle, etc.)
- Video content including personal projects and animations
- HTML pages for browsing the collection
